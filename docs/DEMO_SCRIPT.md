# 2 minute 30 second demo script

## 0:00–0:20 — The problem
“People often lose time and money because a return or warranty issue becomes confusing. A reminder alone doesn't help them work through the process.”

## 0:20–0:45 — Create a case
Click Load demo, explain that the 10-day policy window is intentionally labeled illustrative, then create the case. Show the saved record and deadline calculation.

## 0:45–1:15 — Prepare a next action
Open the case and generate a support-message draft. Explain that it is grounded in stored purchase details and is not sent automatically.

## 1:15–1:40 — Track follow-up
Add a follow-up date and note, then refresh the dashboard to demonstrate persistence.

## 1:40–2:05 — Show the agent/tool layer
Show the MCP server and explain the tools: create case, draft support message, schedule follow-up, update status, and verify case. If an agent host is integrated, demonstrate one multi-step request and display the actual tool results.

## 2:05–2:30 — Close
“Refund Guardian moves beyond a reminder. It structures a consumer issue, prepares a next step, and tracks follow-through while leaving consequential actions under user control.”

## Demo honesty checklist
- Do not call a simulated notification a sent notification.
- Do not claim policy research is live unless it is connected to a real source.
- Do not say a refund is guaranteed.
- Use synthetic purchase data.
