## Project name
Refund Guardian AI

## Tagline
From purchase problem to a clear next step.

## What it does
Refund Guardian is a consumer-support workflow assistant. It records return and warranty issues, keeps purchase facts and policy sources together, drafts support messages for review, and tracks follow-up tasks. Its MCP tools allow an agentic interface to orchestrate these actions and verify persisted results.

## Why we built it
A reminder tells someone that a deadline is coming. It does not help them assemble the information, write a clear support request, or keep track of what happens next. Refund Guardian organizes those steps in one transparent workflow.

## How it works
A user enters purchase information and describes the issue. The app stores a case, optionally calculates a date from a user-verified policy window, generates a support-message draft, and saves follow-up tasks. An MCP server exposes case-management tools to an agent host. The system reads records back to verify changes.
